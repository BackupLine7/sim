# Маршруты на карте

Каждая миссия — отдельный UTF-8 JSON в `config/missions/`:

```json
{
  "name": "Мой учебный маршрут",
  "waypoints": [
    {"latitude_deg": 49.570314, "longitude_deg": 34.38011},
    {"latitude_deg": 49.577, "longitude_deg": 34.399}
  ]
}
```

Координаты WGS84 в градусах; точки соединяются в порядке записи.
Чтобы замкнуть маршрут, повторите первую точку в конце. Допускается 2–1000
точек. Идентификатор миссии — имя файла без расширения.

После изменения файлов нажмите ↻ на карте. Выберите миссию в списке:
появятся голубая пунктирная линия и номера точек. Кнопка ⌖ показывает весь
маршрут. «Без миссии» убирает его. Некорректные файлы показываются как ошибка,
остальные миссии остаются доступны. Файлы перечитываются без рестарта физики.

Выбор миссии в списке только показывает план. Команды в ArduPilot уходят по
кнопке «Следовать».

## Выполнение маршрута

«Следовать» доступна в полёте. Мост поднимает высоту точек до безопасной над
рельефом (`terrain_clearance` в `config/mission-navigation.json`), загружает
маршрут в ArduPilot и включает AUTO.

Две окружности вокруг точки:

- **радиус прицеливания** — `radius_m` из миссии. Его получает автопилот: внутри
  этого радиуса ArduPlane переключается на следующую точку;
- **допуск зачёта** — `radius_m × acceptance_radius_multiplier` по горизонтали и
  `height_tolerance_m` по высоте. Мост засчитывает точку, когда отрезок между
  двумя отсчётами позиции пересёк этот цилиндр.

Допуск шире радиуса прицеливания, поэтому самолёт входит в зону зачёта раньше,
чем автопилот уходит к следующей точке. Засчитанная точка не переключает
автопилот: он сам долетает до радиуса прицеливания.

Если ArduPlane дважды подряд сообщил о переходе дальше, а точка не засчитана,
самолёт прошёл её вне допуска. Мост возвращает его на ту же точку и увеличивает
`mission_missed`. Одно сообщение не считается промахом: оно может прийти раньше
отсчёта позиции, который пересёк цилиндр.

Набор высоты в AUTO начинается сразу (`FLIGHT_OPTIONS`, бит 14, ставит мост).
Иначе ArduPlane растягивает набор на весь участок, и безопасная высота над
рельефом достигается только у следующей точки.

Предел крена на маршруте — `maximum_bank_deg` из настроек самолёта. Радиус
разворота растёт обратно тангенсу крена: F-16 на 600 км/ч при 30° разворачивается
по радиусу 4,9 км, при 65° — 1,3 км.

Не каждый маршрут выполним. Поворот на 90°, спуск на 400 м и участок 6 км на
600 км/ч одновременно — за пределами F-16 под ArduPlane: в крутом вираже со
снижением крылу не хватает подъёмной силы на разворот. Такой маршрут
заканчивается промахом, а не пролётом.

«Север ↑» фиксирует север сверху. «По курсу дрона ↑» вращает карту по направлению
носа самолёта и включает слежение. Перетаскивание карты приостанавливает слежение;
«На самолёт» возобновляет его. Нажатие компаса выбирает север. Кнопка ⛶ переключает
карту между небольшим окном и правой половиной экрана.
