# Динамическая загрузка высот

`config/terrain-streaming.json` задаёт источник, каталог, параллелизм, радиус загрузки, лимит диска и параметры перехода к новым высотам. Пользовательский переключатель интернета сохраняется отдельно в `config/local.terrain-streaming.json`.

Мост по позиции самолёта заказывает текущий HGT-квадрат 1×1 градус и восемь соседних. Два фоновых потока загружают gzip с AWS Mapzen Skadi, проверяют размер HGT и атомарно сохраняют распакованный файл. Сеть не используется внутри расчёта высоты. При ошибке применяется прежний DEM/резервная поверхность; запрос повторяется через 120 секунд. Снимки карты этим механизмом не загружаются.

Один HGT 3601×3601 занимает около 24.7 МиБ. Дисковый лимит по умолчанию 5 ГиБ, память — до 12 плиток при штатном радиусе. Активные соседние плитки защищены от удаления при автоматическом сокращении дискового кеша. Дальние плитки удаляются первыми по времени файла. Данные за пределами покрытия провайдера не выдумываются.

Физика и HTTP-геометрия используют общий TerrainCache в одном процессе. При появлении данных увеличивается ревизия: кеш геометрии сбрасывается, браузер заменяет каждый старый участок после готовности нового.

Если файл готов во время полёта, вокруг позиции самолёта на момент загрузки сохраняется старая поверхность радиусом 3 км, затем выполняется плавное пространственное смешивание ещё на 3 км. Это временная искусственная переходная область для предотвращения внезапного появления земли под аппаратом, а не реальная форма рельефа. На новом полёте переход снимается. Пропускной способности сети может не хватить: отсутствие данных не гарантирует безопасный маршрут. Проверка профиля высот маршрута и автоматический обход гор в эту функцию не входят.

Кнопка очистки удаляет только распознанные `.hgt` из выделенного каталога, без рекурсивного удаления, после завершения загрузок. Используемые массивы остаются в памяти. Текущий район не скачивается повторно сразу после очистки. Исходный DEM Полтавы, снимки, миссии и настройки не удаляются. Кеш — около 24.7 МиБ на плитку, размер в интерфейсе указан по распакованным файлам.
