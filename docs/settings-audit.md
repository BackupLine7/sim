# Проверка настроек

Проверено по текущему коду 2026-09-10. Это проверка подключений и обработчиков, не сертификация аэродинамического диапазона Rascal.

| Настройки | Где применяются | Результат |
|---|---|---|
| Инверсия и чувствительность трёх осей | SettingsPanel.axis → RC override | Подключены, сразу |
| Минимальная, крейсерская, предельная скорость | PreferencesStore.parameters → AIRSPEED_MIN/CRUISE/MAX | Задания и пределы AP, после рестарта самолёта |
| Посадочная скорость | TECS_LAND_ARSPD | Применяется при посадке, после рестарта |
| Высота взлёта и возврата | TKOFF_ALT / RTL_ALTITUDE | Подключены, после рестарта |
| Максимальный крен | ROLL_LIMIT_DEG | Подключён, после рестарта |
| Ветер и направление | SIM_WIND_SPD/DIR → SIM_JSBSim::send_servos → atmosphere/wind-* | Подключены, после рестарта |
| Задание скорости в полёте | AirspeedControl → PARAM_VALUE + DO_CHANGE_SPEED ACK | Команда работает; достижимость зависит от физики |
| Видимость приборов и сетки | SettingsPanel → DOM / WorldStreamer.setDebug | Подключены, сразу |
| Память, сохранение участков, радиус | WorldStreamer.configure / eviction | Подключены; обязательные активные участки могут превышать бюджет |
| Густота и лесополосы | Параметры запроса chunk → WorldStore | Подключены; пересоздание участков |

Неподключённых полей в проверенных группах не найдено. Не удаляем действующие настройки на основании невозможности разогнать Rascal до 339 км/ч: команда была подтверждена, газ достигал 100%, скорость оставалась около 125 км/ч. Названия скорости уточнены как задания AP, а не характеристики двигателя. Остальные параметры проверены по цепочке кода, без изменения текущей миссии.
