# Здания по областям

Настройки → «Здания по областям» показывают административные регионы,
пересекающие `config/world.json → bounds`. Список всегда виден; поиск
подсвечивает совпадения и прокручивает к ним, не скрывая остальные строки.
«Скачать» ставит регион в очередь, «Отменить» отменяет текущую или ожидающую
операцию. Выполняется одна региональная выгрузка одновременно.

Здания — Overture Maps, административные границы — geoBoundaries gbOpen ADM1.
Справочник `config/building-region-catalog.json` входит в проект, поэтому
открытие списка не зависит от интернета. Он подготовлен скриптом
`scripts/prepare_building_regions.py`; страны для выборки определены по
Natural Earth. Украинские регионы расположены первыми. Выпуск зданий и параметры доступа заданы в
`config/building-regions.json`. STAC-индекс сначала отбирает географически
подходящие Parquet-файлы; DuckDB читает нужные столбцы и фильтрует здания
по пересечению с границей области. Загружается вся область, в том числе
её часть за краем карты. Полнота определяется источником, а не наличием
каждого реального здания; при неизвестной высоте используется
`world.json → default_building_height_m`.

Постоянные выгрузки находятся в `data/osm/regions/*.sqlite`. Они содержат
сжатые контуры с индексом по квадратам детализации карты. Это отдельное
хранилище: лимит и очистка временного кеша его не затрагивают. Рельеф,
снимки и деревья эти кнопки не скачивают.

Файл публикуется атомарно только после успешной полной выборки. Ошибка
или отмена удаляет временный `.partial`, сохраняя предыдущую версию.
После перезапуска завершённые выгрузки доступны без сети. Незавершённую
выгрузку нужно запустить снова. Очередь в памяти не восстанавливается.

После публикации меняется версия зданий: загруженные квадраты основной
3D-сцены обновляются. Мини-карта объёмы зданий не рисует.

API: `GET /api/building-regions`; `POST` с JSON
`{"action":"download","id":"ID из списка"}`, действия `cancel` и `catalog`
(повторить получение списка после ошибки). Ответ содержит состояние,
ошибки, количество обработанных зданий и размер завершённых файлов.
