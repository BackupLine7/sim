# JSBSim: абсолютная высота ArduPilot

`jsbsim-absolute-altitude.patch` исправляет `SIM_JSBSim::recv_fdm` для Plane-4.7.1.
FlightGear FDM передаёт отдельно `altitude` и `agl`, обе величины в метрах.
JSBSim в данном запуске инициализирован на высоте 1.3 м относительно нулевой поверхности; географическая высота старта добавляется адаптером.

Было: `home.alt + 100 * fdm.agl`. Это верно только при земле на уровне старта.
Стало: `home.alt + 100 * fdm.altitude`. Высота самолёта больше не зависит от высоты земли под ним.

`scripts/prepare_sitl_overrides.py` копирует исходник в `build/sitl-overrides` и применяет патч к копии. Скрипт Docker-сборки монтирует её только в сборочный контейнер, read-only. Исходный файл на хосте не изменяется. При несовместимом обновлении исходника применение патча завершается ошибкой.
